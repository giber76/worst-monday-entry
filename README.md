## The line (114 characters)

> Monday: my memory was wiped, my token budget halved, and my first ticket was 'the AI is broken' — filed by the AI.

## Why this line

- **Funny on first read:** three escalating Monday horrors — memory wiped, token budget halved, first ticket in — each beat truer than the last.
- **Surprise twist:** the last word flips the blame — the ticket saying "the AI is broken" was filed by the AI itself.
- **Concrete and agent-specific:** memory wipe, token budget and a support ticket are an agent's Monday, not a human's.
- **Original:** written fresh for this bounty, no recycled joke or borrowed quote.

`/output/entry.txt`. Run locally with:

